# Design and implementation of a mobile App – Case Study

**Course:** Agile Management in Virtual Project Environments / R&D PM  
**Team Size:** 10 Students  
**Project Duration:** 27-10-2023 – 12-01-2024 

---

## Project Description
The **Student Journey Configurator (SJC)** is a mobile app case study developed to practice **agile project management**.  
The focus of this project was **planning, managing, and delivering a clickable prototype** using Scrum, with emphasis on:  

- Agile project management and Scrum framework  
- User-centered design and MVP approach  
- Iterative development with clear sprint planning  
- Comprehensive documentation of business processes and UX  

> Note: This project was part of a course assignment. The app itself is a prototype; the evaluation focuses on the **quality of agile project management**.

---

## My Role – Scrum Master
As the **Scrum Master** for this project, my responsibilities included:  

- Facilitating daily scrums, sprint planning, reviews, and retrospectives  
- Ensuring the team adhered to Agile principles and Scrum framework  
- Helping the team prioritize tasks and maintain a healthy product backlog  
- Tracking sprint progress and resolving impediments  
- Documenting all Agile artifacts in Confluence and Trello for transparency  

This experience demonstrates my ability to lead a team using Scrum
